## Why we built VesperFolio

For a while, I had been thinking about building an application that could create PDF documents from images. The idea became a practical need when someone asked me to send a student's work as a PDF.

I tried several applications, but none seemed quite right for the job. I needed something simple: a way to add several images at once, arrange them in the correct order, and turn them into a PDF without confusing controls or unnecessary complications.

That need led to **VesperFolio**, an image-to-PDF creator designed to do what it is supposed to do without making things confusing or requiring users to upload their images to an external service. As the project developed, we added image-based Word export, cropping, previews, and other useful features while keeping local processing and privacy central to its design.

Most of what we design and build grows from a real need. VesperFolio is one of those projects.

**It does not need to do everything. It needs to do its job well.**

## Start

1. Download `index.html` and open it in a modern browser. No installation, server or internet connection is required after downloading.
2. Add photos, arrange, crop or rotate them. Tap a thumbnail for a paper-layout preview. Crop opens a full-window workspace: drag edges/corners, drag inside to move the selection, or use Fine tune for one-pixel adjustments. The floating panel can be hidden; Apply crop confirms, Cancel leaves the image unchanged.
3. Choose document settings, then export PDF or Word. Check the saved file before closing.

The complete application source is a single self-contained web-app file. It includes its own PDF and DOCX writers; there are no runtime packages, fonts, CDN assets or network services. Hosting this file does not make an offline PWA: retain a downloaded copy for offline use. Some Android browsers handle downloaded web-app files differently; test your chosen browser.

## Features

Full-window touch cropping with eight draggable edge/corner handles, movable selection and a hideable semitransparent precision panel; multiple-image import; page ordering; left/right rotation; crop in rotated coordinates; original, grey and document filters; one-image-pixel crop adjustment buttons and keyboard arrows (Shift for ten pixels); eight-step maximum Undo; A4, Letter and per-image sizing; orientation, margins and JPEG quality; document preview; PDF and DOCX download; print; Exit. DOCX contains pictures, without OCR or editable text extraction. Preview describes PDF placement; Word reserves additional vertical room for its paragraphs. Print uses printer settings.

Pages are held in memory for this session. There is no automatic recovery after closing or reloading. Clear pages is reversible with Undo. Discard session clears both pages and history references. Exported files and original images are never deleted by these actions.

Limits: 24 pages, 35 MB per import file, 2200-pixel longest edge, 24 million active image pixels. This may stop imports before 24 pages. Old Undo snapshots are dropped above 32 million retained pixels. Real browser memory usage is higher; decoding large source images can still exhaust a device. Animation is flattened to a frame; supported formats depend on the browser.

## Android wrapper

Optional existing `TurtleNative.save`, `.print` and `.exit` hooks are preserved. The wrapper must support the promise-based save interface used by v2.1. No APK is included in this **source ZIP**. A separate v2.3.2 Android test APK was supplied and independently inspected: the embedded app matches this release, its manifest requests no Android permissions, and its APK v2 signature and signed-content digest verify. The Android package identifier was generated by the wrapper and is not suitable as a stable public identity without a long-term signing/update plan. Earlier v2.3 APK evidence in QA.md concerns an older build that requested unused permissions. Browsers commonly refuse scripted tab closure: Exit then explains that the user can close the tab. Export before exiting or changing an APK configuration that reloads the page.
