## Origin and provenance

HavocRock conceived VesperFolio after needing to turn a student's photographed work into a PDF. To conserve resources, HavocRock requested an initial application from Claude, then shared it with ChatGPT (Vesper), which helped modify and expand it through later versions. HavocRock directed requirements and tested the software.

Claude subsequently told the maintainer that it generated the initial implementation for that conversation, without copying code from a specific repository, using published PDF, ZIP, Office Open XML and standard browser interfaces. That is **a reported provenance statement**, not an independent guarantee of non-infringement. The preserved v2.1 source and current v2.3.2 source contain no bundled third-party runtime library or Google sign-in script; mention of Google Docs describes separately opening a downloaded Word file.
